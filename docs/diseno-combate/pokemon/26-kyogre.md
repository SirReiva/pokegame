# Kyogre

**Tipos:** Agua · **Roles:** Mago / Apoyo · **Dex:** 0382

## Identidad

El dios marino: controla el campo con áreas enormes, charcos y curación de
equipo. Lento, enorme y difícil de matar para el daño especial, pero incapaz de
escapar si le llegan.

## Balance

**Fortalezas:** áreas enormes, charcos, curación propia y de equipo, DE 120, visión 12,2.
**Debilidades:** hurtbox 0,60 (la mayor), 5,9 u/s, sin dash, casteos telegrafiados.

## Decisiones cerradas

- Los charcos no hacen daño y no se acumulan.
- Máximo 3 charcos; se elimina el más antiguo.
- El básico no crea charcos.
- La curación del Pulso llega con el segundo pulso.
